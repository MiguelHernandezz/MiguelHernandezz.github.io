About

The parts of computing I care about most are the ones where security actually happens: networks, operating systems and low-level code.

Lo que más me interesa de la informática es donde de verdad ocurre la seguridad: las redes, los sistemas operativos y el código a bajo nivel.

Everything on this page is real university coursework, cleaned up so anyone can clone it and run it. Where a project could be tested automatically, it is: GitHub Actions builds it on Linux, runs it under sanitizers or against a real PostgreSQL, and fails if something breaks.

Todo lo que hay aquí son prácticas reales de la universidad, preparadas para que cualquiera pueda clonarlas y ejecutarlas. Donde se podía probar automáticamente, se prueba: GitHub Actions las compila en Linux, las ejecuta con sanitizers o contra un PostgreSQL real, y falla si algo se rompe.

CPOSIXLinuxCI · Ubuntu

A Unix minishell and a thread race

Sistemas Operativos · team of 2

A small shell with pipelines, redirection, background jobs and a SIGCHLD handler, plus a POSIX-threads simulation where shared state is guarded by mutexes.

  • fork, execvp and waitpid; pipe and dup2 for pipelines
  • No zombie processes: sigaction with WNOHANG reaping
  • Built and smoke-tested on Ubuntu on every push

PostgreSQL 17SQLPythonCI · PostgreSQL

PostgreSQL from the inside

Bases de Datos Avanzadas · team of 2

Storage and indexes over 30 million rows, query plans, users and privileges, a deadlock between three sessions, point-in-time recovery and replication across four servers.

  • B-tree vs hash indexes, partitioning and VACUUM
  • WAL inspection and PITR after a simulated cluster loss
  • CI starts PostgreSQL and loads the generated data
