About

I'm a third-year Computer Engineering student at the Universidad de Alcalá (UAH), and I'm steering my degree towards cybersecurity. The parts I care about most are where security happens: networks (TCP/IP, routing, VLANs, traffic analysis), operating systems (Linux, POSIX processes and threads, memory) and low-level programming (C and assembly).

Estudio 3º de Ingeniería Informática en la Universidad de Alcalá (UAH) y estoy orientando la carrera hacia la ciberseguridad. Lo que más me interesa es donde ocurre la seguridad: redes (TCP/IP, routing, VLANs, análisis de tráfico), sistemas operativos (Linux, procesos e hilos POSIX, memoria) y programación a bajo nivel (C y ensamblador).

Everything here is real coursework, cleaned up so anyone can download and run it. Where a project could be tested automatically, it is: GitHub Actions builds it on Linux, runs it under sanitizers or against a real PostgreSQL, and fails if something breaks.

Todo lo que hay aquí son prácticas reales, preparadas para que cualquiera pueda descargarlas y ejecutarlas. Donde se podía probar automáticamente, se prueba: GitHub Actions las compila en Linux, las ejecuta con sanitizers o contra un PostgreSQL real, y falla si algo se rompe.

Next up: a home SOC lab (attacker VM, monitored targets, SIEM and IDS) to reproduce attacks and write the detections for them.

Lo siguiente: un laboratorio SOC propio (máquina atacante, objetivos monitorizados, SIEM e IDS) para reproducir ataques y escribir cómo detectarlos.
